# Under Development!
This is a repository for skills astronomers might need, and in many cases already have, in order to transition into industries like data science and aerospace. For now we only have one page: [skills](Skills)!

If you're a member of the aas-bacac github organization you can directly edit any page by clicking the button on the top right.  Otherwise, feel free to suggest changes to us by going to the issues [section](https://github.com/aas-bacac/skills/issues) above and click "new issue" and let us know what changes you think need need to be made.

# How to use this list
This list is meant to be a starting point for astronomers interested in moving into industry.  We want to both give you (A) the building blocks for how to translate your existing CV into an industry-facing resume and (B) give you some direction for what skills you should learn in preparation for this transition.  If you think your industry-transition is a ways in the future, you could also use this list to help you focus on what classes or research projects you'd like to take on so that you'll have more career options later on.  If you're in astronomy education, then this list can help you craft a curriculum that will be relevant to students who might want to end up working in industry.
